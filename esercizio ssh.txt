(E' una simulazione da cio che avviene da CMD, le parti che iniziano col - sono quelle le risposte del computer)

1(generazione chiavi)
ssh-keygen -t ed25519 -C "viscomi.nicolo@w4s.filippobilardo.it"
-Generating public/private ed25519 key pair.
Enter file in which to save the key (C:\Users\TUO_UTENTE\.ssh\id_ed25519): (qui premo invio)
-Enter passphrase (empty for no passphrase): (scrivo la password che non sarà visualizzabile)
-Enter same passphrase again: (la riscrivo uguale)
-Your identification has been saved in C:\Users\TUO_UTENTE\.ssh\id_ed25519
Your public key has been saved in C:\Users\TUO_UTENTE\.ssh\id_ed25519.pub

2(verifica chiavi)
dir %USERPROFILE%\.ssh
-id_ed25519
id_ed25519.pub


3(visualizazione chiavi)
type %USERPROFILE%\.ssh\id_ed25519.pub
-ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIGx... viscomi.nicolo@filippobilardo.w4s.it (chiave pubblica)


4(copiare chiave sul server)

server:
w4s.filippobilardo.it
porta 2222
utente: viscomi.nicolo

scp -P 2222 %USERPROFILE%\.ssh\id_ed25519.pub viscomi.nicolo@w4s.filippobilardo.it:~/id_ed25519.pub
ssh -p 2222 viscomi.nicolo@w4s.filippobilardo.it
mkdir -p ~/.ssh
chmod 700 ~/.ssh
cat ~/id_ed25519.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
rm ~/id_ed25519.pub
exit


5(test connessione)
ssh -i %USERPROFILE%\.ssh\id_ed25519 -p 2222 viscomi.nicolo@w4s.filippobilardo.it
